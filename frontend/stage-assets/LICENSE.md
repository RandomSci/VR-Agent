# Stage assets

Everything in sprites/, particles/ and backgrounds/ is original art made for
VR Agent (Selwyn Builds). You may use it in anything Mika and Luna build and
publish.

characters/ holds still images rendered from the Live2D models the stream
already uses (mao_pro for Mika, Hiyori for Luna). They are covered by the
same license as those models (Live2D Free Material License). Check that
license before using them outside the stream and its published games, and
delete this folder if you ever stop using those models.
